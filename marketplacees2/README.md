MARKETPLACE

## O seguinte sistema tem como objetivo simular o funcionamento de um marketplace online para o projeto da disciplina de Engenharia de Software II.

## Requisitos:

### 1 -> Java Development Kit (JDK) 11 ou superior

## Passo a passo para a execução do código:

### 1 -> Certifique-se que o Java está instalado em sua máquina:
    java -version

### 2 -> Clone o repositório:
    git clone https://github.com/rachelwitchburn/Marketplace.ES2.git

### 3 -> Navegue até a pasta em que o repositório foi clonado:
    cd Marketplace.ES2

### 4 -> Compile o código:
    javac -d bin src/com/marketplace/*.java

### 5 -> Execute o programa:
    java -cp bin com.marketplace.Main
